# تشغيل موقع نتائج مسابقة مسجد النور

## 1) إنشاء قاعدة البيانات (Supabase)
1. ادخل على supabase.com وسجّل بحساب GitHub، ثم **New project** (اختر أي اسم وكلمة مرور قوية لقاعدة البيانات، والمنطقة الأقرب لك).
2. من القائمة اليسرى: **SQL Editor** ← **New query** ← الصق محتوى ملف `schema.sql` كاملًا ← **Run**. لازم تظهر رسالة Success.

## 2) إنشاء حساب الإدارة
1. **Authentication** ← **Users** ← **Add user** ← **Create new user**.
2. اكتب بريدك وكلمة مرور قوية، وفعّل **Auto Confirm User**.
3. **Authentication** ← **Sign In / Providers** (أو Settings) ← أوقف **Allow new users to sign up** (مهم جدًا حتى لا يستطيع أحد إنشاء حساب إدارة غيرك).

## 3) ربط الموقع بقاعدة البيانات
1. **Project Settings** ← **API**.
2. انسخ **Project URL** و **anon public key** والصقهما في ملف `config.js`.
   (مفتاح `anon` مصمم للظهور في الموقع العام. لا تنسخ أبدًا مفتاح `service_role`.)

## 4) النشر على GitHub Pages
ارفع الملفات `index.html` و `admin.html` و `config.js` و `mosque.jpg` إلى مستودع `quran-results` الحالي (استبدل القديم)، وبعد دقيقة يعمل الرابط:
- للمتسابقين: `https://ahmedmaree2007-star.github.io/quran-results/`
- للإدارة (لا ترسله لأحد): `.../admin.html`

## 5) الاستخدام
- سجّل دخول من `admin.html`.
- أضف النتائج واحدة واحدة، أو املأ `قالب_النتائج.xlsx` (احذف صف المثال) وارفعه بزر **رفع ملف Excel**.
- من **الإعدادات**: حدّد درجة النجاح (الافتراضي 60، غيّره حسب نظام المسابقة)، وعدد الأوائل، وأظهر قائمة الأوائل أو أخفِها.
- المتسابق يدخل رقمه فقط فيرى نتيجته ومركزه داخل فرعه، ولا يستطيع رؤية أي نتيجة أخرى.

## 6) قبل إرسال الرابط
جرّب بنفسك: أضف متسابقًا تجريبيًا وابحث برقمه من الصفحة العامة (من هاتف أو نافذة خاصة)، ثم احذفه.

## ملاحظة
الخطة المجانية في Supabase تكفي لمئات النتائج. وإذا لم يستخدم أحد المشروع أسبوعًا يتوقف مؤقتًا ويعود بزر واحد، فادخل عليه قبل يوم النتائج.
